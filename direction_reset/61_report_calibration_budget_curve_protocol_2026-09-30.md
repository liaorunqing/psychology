# CES–Marian 报告校准预算曲线协议

**状态：2026-09-30；写于运行本次预算曲线、查看其误差结果之前。** 本分析由既有 CES 与 Marian 历史结果启发，属于事后、探索性机制检验，不属于原 OSF 注册。其目的不是再次筛选最好看的结局或算法，而是量化固定数量的早期本人报告可为后续心理状态估计提供多少信息。

## 研究问题与样本

问题是：在预测同一批较晚心理状态时，将可见的早期本人报告从 2 次增加到 3、4、6、8 次，误差是否呈现跨设计一致的递减与边际收益衰减？

- **CES**：只使用此前已冻结的 110 人共同心理测量开发表中的 PHQ-2。PHQ-2 在每个外层训练折内标准化。只有至少 9 次保留评估者进入本分析。
- **Marian**：共同主要结局为 `anhedonia` 与 `depressed`，保留 1–4 原始有序评分；仅 `status=1` 作为完整报告。所有至少 9 次完整报告者进入本分析。

预算固定为 `2, 3, 4, 6, 8`。为避免不同预算比较不同目标，所有预算均只在每人第 9 次及之后的完整报告上评分。每个数据集/结局/折内的所有预算必须具有完全相同的参与者、目标键与真实结局。记录数不能替代参与者数。

## 固定预算预测器

对预算 `b`，模型只能看见每人最初 `b` 次完整报告；第 `b+1` 次及之后的真实报告均不更新该预测器。预测为：

`P_b = mean(first b reports) + w_b × (b-th report − mean(first b reports))`，其中 `0 ≤ w_b ≤ 1`。

`w_b` 只在相应外层训练参与者的共同目标（第 9 次及之后）上最小化参与者等权绝对误差。权重网格固定为 `0, 0.025, ..., 1`；若并列，选择较小权重。此规则优先配合主要 MAE，避免把单一离散题项过度解释为等距连续变量。

另报告一个“持续更新”上界 `R_online`：在每个目标前，使用此前全部完整报告的均值和最近一次报告，权重同样仅在训练参与者上按上述网格选择。它使用超过 8 次的报告，不属于相同固定预算比较，只用于显示继续更新相对于八次后冻结的剩余信息。

预算同时改变报告数量和最后一次可见报告的时间；本分析不能把改善单独归因于重复测量的统计平均或时间更新。它是固定早期校准信息实验，不是随机化问卷负担试验，也不推导最优提示频率。

## 验证与推断

使用已有的随机种子 `20260918` 和参与者级五折。CES 沿用既有折映射；Marian 沿用 `59` 号实验的确定性参与者折。所有标准化、权重调节都只在外层训练参与者中完成。

主要指标是参与者等权 MAE，次要指标为参与者等权 RMSE。主要相邻对比固定为 `3−2`、`4−3`、`6−4`、`8−6`；另报告 `R_online−8`。相对变化的负值表示后者误差更低。使用 2,000 次参与者级 bootstrap 得到描述性 95% 区间。三个结局全部报告，不因效果大小删除任一结局；不使用 p 值定义阳性结果。

预先定义的解释规则：

1. 若三个结局的相邻预算 MAE 都总体递减，且后段改善小于前段，则支持“早期报告存在边际收益衰减”的方向性证据。
2. 若不同结局曲线形状冲突，则不形成跨构念规律，只分别报告。
3. 若 `R_online` 明显优于固定 8 次，只能说明八次后仍有新的状态信息，不能说明要求更多问卷会因果改善结局。
4. 单次小于 2% 且区间跨 0 的改善视为信息有限，不包装为实质增益。

必须自动验证：当前和未来标签不进入固定预算特征；预算较小者的特征不受第 `b+1` 次报告改值影响；所有预算目标键相同；训练/测试 ID 无交叉；每位训练参与者总损失权重相等；CES 标准化只用训练参与者；每张结果表包含参与者数和目标数。任何检查失败时停止解释。
